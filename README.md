# Échecs Lunettes

Application Android : la caméra des lunettes Ray-Ban Meta regarde l'échiquier,
l'application reconnaît le coup de l'adversaire, demande à Stockfish la réponse
et l'annonce à voix haute.

L'application est fabriquée automatiquement par GitHub à chaque envoi
(onglet « Actions »), et publiée dans « Releases ».
